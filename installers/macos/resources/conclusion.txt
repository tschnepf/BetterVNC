The BetterVNC guest agent is installed and running as "BetterVNC Agent"; look for its icon in the menu bar.

Two macOS permissions make everything work. Both are in System Settings, Privacy & Security, where macOS lists "BetterVNC Agent" once the agent has asked:

  Accessibility: needed for smooth scrolling. Switch BetterVNC Agent on.

  Screen & System Audio Recording (Screen Recording before macOS 15): needed for the "Stream" picture modes. macOS asks the first time a viewer starts a stream; switch BetterVNC Agent on, accept "Quit & Reopen" if offered, and the stream starts.

If BetterVNC Agent is not in a list, click +, open the Applications folder and choose BetterVNC Agent. The agent's menu bar item has Permissions…, which walks through both.

In BetterVNC on your PC, edit the connection, tick "Use the guest agent", connect, and click Allow in the dialog that appears on this screen.
